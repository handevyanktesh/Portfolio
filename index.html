    Rigora

    Full-stack, built end to end

    AI-powered PC builder and compatibility assistant

    Real parts catalog› Gemini picks a build› Compatibility check› Verified build

    Give Rigora a budget and a use case and it recommends a full set of parts. The AI never works from memory, and no build reaches the user unchecked.

    • The AI only sees real products. Gemini chooses from in-stock parts pulled from the catalog, so it can’t invent a part or a price.
    • Every build is re-checked. A separate compatibility service verifies it before the result is shown, and returns the reason for every failure.
    • One editor for every build. Builds made by the AI and by hand open in the same editor, with live checks.

    Also includes JWT login, cart, wishlist, saved builds, a dashboard, and an admin panel with role-based access.

    MindMap

    In development

    Real-time student attention and confusion detector, team project

    Webcam in browser› Face landmarks› Reliable face?› Eye, gaze, head features› Attention estimate

    MindMap estimates how engaged a student is during an online class and shows the teacher a live summary, while keeping video private. Results are estimates of behaviour, not a diagnosis.

    • Video never leaves the browser. Only numbers such as eye openness, gaze and head angles are sent on.
    • No face means no guess. If a face can’t be found reliably, the system reports no confident reading instead of scoring the student as inattentive.
    • Behaviour over time, not single frames. Signals are combined across a time window, so a quick glance away isn’t treated as distraction.

    Current focus: feature extraction, model comparison, scoring and the live teacher dashboard.

    React, MediaPipe Face Mesh, FastAPI, WebSockets, MongoDB, scikit-learn
